The ICSE course covers only order, addition, subtraction, scalar multiplication and matrix multiplication of matrices up to 2×2. Determinants and inverses are NOT in the syllabus.

Multiplication rule: A(m×n) × B(n×p) is defined only when the inner numbers match, and the product has order m×p. Row of the first times column of the second. Matrix multiplication is NOT commutative — AB ≠ BA in general.

A. Worked Problems

Q1. AB — take each ROW of A against each COLUMN of B.

Row 1 of A = (2, 1):
with column 1 of B (1, 2): 2(1) + 1(2) = 4
with column 2 of B (0, 3): 2(0) + 1(3) = 3
Row 2 of A = (3, −1):
with column 1 of B: 3(1) + (−1)(2) = 3 − 2 = 1
with column 2 of B: 3(0) + (−1)(3) = −3

**AB = [[4, 3], [1, −3]]**

BA — now rows of B against columns of A.

Row 1 of B = (1, 0):
with column 1 of A (2, 3): 1(2) + 0(3) = 2
with column 2 of A (1, −1): 1(1) + 0(−1) = 1
Row 2 of B = (2, 3):
with column 1 of A: 2(2) + 3(3) = 4 + 9 = 13
with column 2 of A: 2(1) + 3(−1) = 2 − 3 = −1

**BA = [[2, 1], [13, −1]]**

**AB ≠ BA.** Matrix multiplication is not commutative, and this is exactly what the question is set to demonstrate.

Q2. Multiply out the left side. A 2×2 times a 2×1 gives a 2×1.

Row 1: 3(1) + 2(y) = 3 + 2y
Row 2: x(1) + 1(y) = x + y

So [[3 + 2y], [x + y]] = [[7], [5]]

EQUATE CORRESPONDING ELEMENTS — two matrices are equal only if every corresponding element is equal.

3 + 2y = 7 → 2y = 4 → **y = 2**
x + y = 5 → x + 2 = 5 → **x = 3**

CHECK: [[3,2],[3,1]] × [[1],[2]] = [[3+4],[3+2]] = [[7],[5]] ✓

Q3. STEP 1 — find A² = A × A.
Row 1 = (1, 2):
column 1 (1, 3): 1(1) + 2(3) = 7
column 2 (2, 4): 1(2) + 2(4) = 10
Row 2 = (3, 4):
column 1: 3(1) + 4(3) = 15
column 2: 3(2) + 4(4) = 22
A² = [[7, 10], [15, 22]]

STEP 2 — find 5A (scalar multiplication: multiply every element).
5A = [[5, 10], [15, 20]]

STEP 3 — find 2I, where I = [[1, 0], [0, 1]].
2I = [[2, 0], [0, 2]]

STEP 4 — combine, element by element.
A² − 5A + 2I
= [[7 − 5 + 2, 10 − 10 + 0], [15 − 15 + 0, 22 − 20 + 2]]
= **[[4, 0], [0, 4]]**

Note that the result is 4I — a pleasant check that the arithmetic is right, since these questions are usually constructed to give a tidy answer.
