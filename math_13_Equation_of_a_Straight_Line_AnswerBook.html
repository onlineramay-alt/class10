SLOPE between two points: m = (y₂ − y₁)/(x₂ − x₁)
SLOPE from an equation: rearrange to y = mx + c; the coefficient of x is the slope.
POINT–SLOPE FORM: y − y₁ = m(x − x₁)
SLOPE–INTERCEPT FORM: y = mx + c

PARALLEL lines have EQUAL slopes: m₁ = m₂
PERPENDICULAR lines have m₁ × m₂ = −1 (each slope is the negative reciprocal of the other)

A line parallel to the x-axis has slope 0 and equation y = c. A line parallel to the y-axis has an undefined slope and equation x = k.

A. Multiple Choice Questions

Q1. (a) y = 6.

A line PARALLEL TO THE X-AXIS is horizontal, so its slope is 0. Using y = mx + c with m = 0 and c = 6 (the y-intercept):
y = 0(x) + 6
**y = 6**

Every point on this line has y-coordinate 6, whatever its x — which is exactly what a horizontal line through (0, 6) means.

Do not confuse it with x = 6, which is a line parallel to the Y-axis.

Official Answer

Q2. (d) 3x + 4y = 0. A parallel line has the same slope, so it has the form 3x + 4y + c = 0. Passing through the origin (0, 0) gives c = 0.

Official Answer

Q3. (b) 2x − 3y = 0. A line passes through the origin only if (0, 0) satisfies it, i.e. there is no constant term. Substituting (0, 0) into 2x − 3y = 0 gives 0 = 0.

Official Answer

Q4. (b) x − y = 7. A line equally inclined to the axes makes 45° with each, so its slope is ±1. Writing x − y = 7 as y = x − 7, the slope is 1.

Official Answer

B. Worked Problems

Q5. STEP 1 — find the slope of the given line by rearranging it into y = mx + c form.
3x + 4y = 7
4y = −3x + 7
y = (−3/4)x + 7/4
So m₁ = −3/4.

STEP 2 — find the slope of the perpendicular.
For perpendicular lines m₁ × m₂ = −1.
(−3/4) × m₂ = −1
m₂ = −1 ÷ (−3/4) = 4/3

STEP 3 — use the point–slope form with the point (2, 3).
y − y₁ = m(x − x₁)
y − 3 = (4/3)(x − 2)

Multiply throughout by 3 to clear the fraction:
3(y − 3) = 4(x − 2)
3y − 9 = 4x − 8

Rearrange:
**4x − 3y + 1 = 0**

CHECK: substitute (2, 3) → 4(2) − 3(3) + 1 = 8 − 9 + 1 = 0 ✓ The point lies on the line.
Check the slopes: the new line has slope 4/3, and (−3/4)(4/3) = −1 ✓

Q6. STEP 1 — find the slope.
m = (y₂ − y₁)/(x₂ − x₁)
= (−7 − 5)/(4 − (−2))
= −12/6
= −2

STEP 2 — use the point–slope form with either point. Taking A(−2, 5):
y − 5 = −2(x − (−2))
y − 5 = −2(x + 2)
y − 5 = −2x − 4
2x + y − 1 = 0

**2x + y − 1 = 0** (equivalently y = −2x + 1)

CHECK BOTH POINTS:
At A(−2, 5): 2(−2) + 5 − 1 = −4 + 5 − 1 = 0 ✓
At B(4, −7): 2(4) + (−7) − 1 = 8 − 7 − 1 = 0 ✓

Always verify with the point you did NOT use to build the equation — that is what catches a slope error.

Q7. STEP 1 — find A, where the line meets the X-AXIS. On the x-axis, y = 0.
2x − 3(0) + 6 = 0
2x = −6
x = −3
**A = (−3, 0)**

STEP 2 — find B, where the line meets the Y-AXIS. On the y-axis, x = 0.
2(0) − 3y + 6 = 0
−3y = −6
y = 2
**B = (0, 2)**

STEP 3 — the line through A parallel to the given line.
A parallel line has the SAME slope. But note that A already lies ON the given line, so the line through A parallel to it IS the given line itself:
**2x − 3y + 6 = 0**

This is worth pausing over. If a question asks for a line through a point parallel to a given line, always check first whether the point lies on that line — if it does, the answer is the line itself, and writing out a fresh equation is unnecessary. Substituting A(−3, 0) into 2x − 3y + 6 gives −6 − 0 + 6 = 0, confirming it.
