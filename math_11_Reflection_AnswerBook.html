The five reflections in the syllabus, and the rule for each:

In the X-AXIS: (x, y) → (x, −y) — the y changes sign
In the Y-AXIS: (x, y) → (−x, y) — the x changes sign
In the ORIGIN: (x, y) → (−x, −y) — both change sign
In the line x = a: (x, y) → (2a − x, y)
In the line y = b: (x, y) → (x, 2b − y)

INVARIANT POINTS are points that map to themselves. A point is invariant under reflection in a line if and only if it LIES ON that line.

A. Worked Problems

Q1. REFLECTION OF P(3, −5) IN THE X-AXIS: the y-coordinate changes sign.
P′ = **(3, 5)**

REFLECTION OF P′(3, 5) IN THE Y-AXIS: the x-coordinate changes sign.
P″ = **(−3, 5)**

WHAT SINGLE TRANSFORMATION MAPS P TO P″?
P(3, −5) → P″(−3, 5). BOTH coordinates have changed sign, which is reflection in the ORIGIN.

**A single reflection in the origin.**

GENERAL RESULT WORTH REMEMBERING: reflection in the x-axis followed by reflection in the y-axis (in either order) is equivalent to a single reflection in the origin, which is the same as a rotation of 180° about the origin.

Q2. REFLECTION OF A(4, −2) IN THE LINE x = 1.
Rule: (x, y) → (2a − x, y), with a = 1.
New x = 2(1) − 4 = 2 − 4 = −2
y is unchanged = −2
A′ = **(−2, −2)**

CHECK by distance: A is at x = 4, which is 3 units to the RIGHT of the line x = 1. So A′ must be 3 units to the LEFT, at x = 1 − 3 = −2 ✓

REFLECTION OF B(−3, 5) IN THE LINE y = 2.
Rule: (x, y) → (x, 2b − y), with b = 2.
x is unchanged = −3
New y = 2(2) − 5 = 4 − 5 = −1
B′ = **(−3, −1)**

CHECK by distance: B is at y = 5, which is 3 units ABOVE the line y = 2. So B′ must be 3 units BELOW, at y = 2 − 3 = −1 ✓

The distance check is worth doing every time — it catches a sign error instantly.

Q3. A point is INVARIANT under reflection in a line when it maps to itself — which happens if and only if the point LIES ON that line.

(i) INVARIANT IN THE X-AXIS: the x-axis is the line y = 0, so the point must have y = 0.
A(2, 0) has y = 0 ✓
B(0, −3) has y = −3 ✗
C(−4, 0) has y = 0 ✓
D(5, 5) has y = 5 ✗
**A and C are invariant in the x-axis.**

(ii) INVARIANT IN THE Y-AXIS: the y-axis is the line x = 0, so the point must have x = 0.
A(2, 0) ✗, B(0, −3) ✓, C(−4, 0) ✗, D(5, 5) ✗
**Only B is invariant in the y-axis.**

NOTE that the ORIGIN (0, 0) is the only point invariant under reflection in BOTH axes, and it is also the only point invariant under reflection in the origin.
