Mathematics — Factorisation of Polynomials (Remainder and Factor Theorem)

ICSE Class 10 Answer Book

Generated 2026-09-10

REMAINDER THEOREM: when f(x) is divided by (x − a), the remainder is f(a).
FACTOR THEOREM: (x − a) is a factor of f(x) if and only if f(a) = 0.

For a divisor of the form (x + a), the value to substitute is x = −a. For (ax − b), substitute x = b/a. Getting the sign wrong here is the single commonest error in the chapter.

A. Multiple Choice Questions

Q1. (b) −16.

Let f(x) = x³ + 7x² + 3x + 2. The divisor is (x + 2), so substitute x = −2.

f(−2) = (−2)³ + 7(−2)² + 3(−2) + 2
= −8 + 7(4) − 6 + 2
= −8 + 28 − 6 + 2
= **16**

By the remainder theorem, the remainder is 16. To make the polynomial exactly divisible, the remainder must become zero — so we must ADD −16 (that is, subtract 16).

**Answer: −16**

NOTE the sign carefully. The remainder is +16, so what is ADDED is −16. Candidates who answer 16 have found the remainder correctly and then failed the last step.

Q8. By the REMAINDER THEOREM, the remainder on dividing f(x) by (x − 2) is f(2).

f(x) = 2x³ − 5x² + 3x − 1

f(2) = 2(2)³ − 5(2)² + 3(2) − 1
= 2(8) − 5(4) + 6 − 1
= 16 − 20 + 6 − 1
= **1**

The remainder is **1**.

Note how much shorter this is than long division — which is the whole point of the theorem, and why examiners set it.

Q9. STEP 1 — apply the FACTOR THEOREM.
f(x) = x³ − 2x² − 5x + 6
f(3) = 27 − 2(9) − 5(3) + 6 = 27 − 18 − 15 + 6 = **0**

Since f(3) = 0, **(x − 3) is a factor.** ∎

STEP 2 — divide to find the other factor. Dividing x³ − 2x² − 5x + 6 by (x − 3) gives the quotient x² + x − 2.

(Working by long division: x³ ÷ x = x²; x²(x − 3) = x³ − 3x²; subtract to leave x² − 5x. Then x² ÷ x = x; x(x − 3) = x² − 3x; subtract to leave −2x + 6. Then −2x ÷ x = −2; −2(x − 3) = −2x + 6; subtract to leave 0.)

STEP 3 — factorise the quadratic quotient.
x² + x − 2 = x² + 2x − x − 2 = x(x + 2) − 1(x + 2) = (x + 2)(x − 1)

COMPLETE FACTORISATION:
**x³ − 2x² − 5x + 6 = (x − 3)(x + 2)(x − 1)**

CHECK by expanding, or by testing a value: at x = 1, the original gives 1 − 2 − 5 + 6 = 0, and the factorised form gives (−2)(3)(0) = 0 ✓

Q10. Let f(x) = x³ + ax² + bx − 8.

CONDITION 1 — (x − 2) is a factor, so f(2) = 0.
8 + 4a + 2b − 8 = 0
4a + 2b = 0
Divide by 2: **2a + b = 0** …(i)

CONDITION 2 — the remainder on division by (x − 3) is 10, so f(3) = 10.
27 + 9a + 3b − 8 = 10
9a + 3b + 19 = 10
9a + 3b = −9
Divide by 3: **3a + b = −3** …(ii)

SOLVE the simultaneous equations. Subtract (i) from (ii):
(3a + b) − (2a + b) = −3 − 0
a = −3

Substitute into (i):
2(−3) + b = 0
−6 + b = 0
b = 6

**a = −3, b = 6**

CHECK: f(x) = x³ − 3x² + 6x − 8.
f(2) = 8 − 12 + 12 − 8 = 0 ✓ (so x − 2 is a factor)
f(3) = 27 − 27 + 18 − 8 = 10 ✓ (so the remainder is 10)
