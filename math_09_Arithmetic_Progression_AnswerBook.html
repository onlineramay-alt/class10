Two formulae carry the whole chapter:

nTH TERM: aₙ = a + (n − 1)d
SUM OF n TERMS: Sₙ = (n/2)[2a + (n − 1)d] or Sₙ = (n/2)(a + l) when the last term l is known.

Here a is the first term, d the common difference, n the number of terms. Almost every problem gives you two of a, d, n, aₙ, Sₙ and asks for a third.

Q1. a = 7
d = 11 − 7 = 4 (check: 15 − 11 = 4 ✓, so it is indeed an AP)
n = 20

aₙ = a + (n − 1)d
a₂₀ = 7 + (20 − 1)(4)
= 7 + 19 × 4
= 7 + 76
= **83**

Q2. STEP 1 — write each condition as an equation.
a₄ = a + 3d = 11 …(i)
a₁₀ = a + 9d = 29 …(ii)

STEP 2 — subtract (i) from (ii):
(a + 9d) − (a + 3d) = 29 − 11
6d = 18
**d = 3**

STEP 3 — substitute into (i):
a + 3(3) = 11
a + 9 = 11
**a = 2**

STEP 4 — the sum of 20 terms.
S₂₀ = (n/2)[2a + (n − 1)d]
= (20/2)[2(2) + 19(3)]
= 10[4 + 57]
= 10 × 61
= **610**

CHECK: the AP is 2, 5, 8, 11, … so the 4th term is 11 ✓ and the 10th is 2 + 27 = 29 ✓

Q3. a = 3, d = 8 − 3 = 5, Sₙ = 1575. Find n.

Sₙ = (n/2)[2a + (n − 1)d]
1575 = (n/2)[2(3) + (n − 1)(5)]
1575 = (n/2)[6 + 5n − 5]
1575 = (n/2)(5n + 1)

Multiply both sides by 2:
3150 = n(5n + 1)
5n² + n − 3150 = 0

Solve by the quadratic formula, with a = 5, b = 1, c = −3150:
D = b² − 4ac = 1 − 4(5)(−3150) = 1 + 63,000 = 63,001
√63,001 = 251

n = [−1 ± 251] / (2 × 5)
n = 250/10 = 25 or n = −252/10 = −25.2

n counts terms, so it must be a POSITIVE WHOLE NUMBER. The negative root is rejected.

**n = 25**

CHECK: S₂₅ = (25/2)[6 + 24(5)] = (25/2)(126) = 25 × 63 = 1575 ✓

NOTE the final step. In every problem of this kind the quadratic gives two roots and one is inadmissible — negative or fractional — because n counts terms. Reject it explicitly and give the reason; marks are awarded for that.

Q4. STEP 1 — identify the sequence. The two-digit multiples of 7 run from 14 to 98:
14, 21, 28, …, 98
This is an AP with a = 14, d = 7, last term l = 98.

STEP 2 — find how many terms there are.
aₙ = a + (n − 1)d
98 = 14 + (n − 1)(7)
84 = 7(n − 1)
n − 1 = 12
**n = 13**

STEP 3 — find the sum, using the form with the last term.
Sₙ = (n/2)(a + l)
S₁₃ = (13/2)(14 + 98)
= (13/2)(112)
= 13 × 56
= **728**

CHECK the count independently: the multiples of 7 from 14 to 98 are 7×2 up to 7×14, that is 13 numbers ✓
