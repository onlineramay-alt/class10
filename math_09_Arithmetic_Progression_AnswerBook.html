Two formulae carry the whole chapter:

nTH TERM: aₙ = a + (n − 1)d
SUM OF n TERMS: Sₙ = (n/2)[2a + (n − 1)d] or Sₙ = (n/2)(a + l) when the last term l is known.

Here a is the first term, d the common difference, n the number of terms. Almost every problem gives you two of a, d, n, aₙ, Sₙ and asks for a third.

Q6. a = 3, d = 8 − 3 = 5, Sₙ = 1575. Find n.

Sₙ = (n/2)[2a + (n − 1)d]
1575 = (n/2)[2(3) + (n − 1)(5)]
1575 = (n/2)[6 + 5n − 5]
1575 = (n/2)(5n + 1)

Multiply both sides by 2:
3150 = n(5n + 1)
5n² + n − 3150 = 0

Solve by the quadratic formula, with a = 5, b = 1, c = −3150:
D = b² − 4ac = 1 − 4(5)(−3150) = 1 + 63,000 = 63,001
√63,001 = 251

n = [−1 ± 251] / (2 × 5)
n = 250/10 = 25 or n = −252/10 = −25.2

n counts terms, so it must be a POSITIVE WHOLE NUMBER. The negative root is rejected.

**n = 25**

CHECK: S₂₅ = (25/2)[6 + 24(5)] = (25/2)(126) = 25 × 63 = 1575 ✓

NOTE the final step. In every problem of this kind the quadratic gives two roots and one is inadmissible — negative or fractional — because n counts terms. Reject it explicitly and give the reason; marks are awarded for that.

Q7. STEP 1 — identify the sequence. The two-digit multiples of 7 run from 14 to 98:

S₁₃ = (13/2)(14 + 98)

= 13 × 56
= **728**

CHECK the count independently: the multiples of 7 from 14 to 98 are 7×2 up to 7×14, that is 13 numbers ✓
