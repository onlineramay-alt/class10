One rule governs the whole chapter: when both sides of an inequation are multiplied or divided by a NEGATIVE number, the sign REVERSES. Everything else is ordinary equation solving. The solution set must always be stated for the replacement set given, and the graph drawn on a number line when asked.

A. Worked Problems

Q1. 3x − 5 ≤ 7 + x

Collect the x terms on the left and the constants on the right:
3x − x ≤ 7 + 5
2x ≤ 12

Divide both sides by 2 (POSITIVE, so the sign does not change):
x ≤ 6

The replacement set is N, the natural numbers, so x may be 1, 2, 3, 4, 5 or 6.

**Solution set = {1, 2, 3, 4, 5, 6}**

ON THE NUMBER LINE: mark dots at 1, 2, 3, 4, 5 and 6 only. Because the replacement set is the natural numbers and not the real numbers, the solution consists of ISOLATED POINTS, not a continuous thick line. Drawing a continuous line here is the standard error.

Q2. This is a double inequation, so operate on ALL THREE parts at once.

−4 ≤ 3 − 2x < 8

Subtract 3 throughout:
−4 − 3 ≤ −2x < 8 − 3
−7 ≤ −2x < 5

Divide throughout by −2. **The number is NEGATIVE, so both inequality signs REVERSE:**
−7/(−2) ≥ x > 5/(−2)
3.5 ≥ x > −2.5

Rewrite in the conventional order, smallest first:
−2.5 < x ≤ 3.5

**Solution set = {x : −2.5 < x ≤ 3.5, x ∈ R}**

ON THE NUMBER LINE: a thick continuous line from −2.5 to 3.5, with an OPEN circle at −2.5 (excluded, because the sign is <) and a CLOSED dot at 3.5 (included, because the sign is ≤). Since the replacement set is R, the line is continuous.

THE TWO THINGS EXAMINERS CHECK HERE: that both signs reversed on dividing by −2, and that the open and closed circles are the right way round.

Q3. First convert the mixed number: 1(5/6) = 11/6.

−2 ≤ 1/2 − 2x/3 ≤ 11/6

Multiply throughout by 6, the LCM of 2, 3 and 6 (POSITIVE, so signs unchanged):
−12 ≤ 3 − 4x ≤ 11

Subtract 3 throughout:
−15 ≤ −4x ≤ 8

Divide throughout by −4. **NEGATIVE, so both signs REVERSE:**
−15/(−4) ≥ x ≥ 8/(−4)
3.75 ≥ x ≥ −2

Rewrite smallest first:
−2 ≤ x ≤ 3.75

The replacement set is N, so x ∈ {1, 2, 3}.

**Solution set = {1, 2, 3}**

ON THE NUMBER LINE: dots at 1, 2 and 3 only — isolated points, not a continuous line, because x is a natural number.

NOTE that −2, −1 and 0 satisfy the inequation as an inequality but are NOT in the solution set, because they are not natural numbers. Always apply the replacement set at the END, after solving.

Q4. (x − 4)/2 ≥ (x + 1)/3 − 1

Multiply throughout by 6, the LCM of 2 and 3 (positive, signs unchanged):
3(x − 4) ≥ 2(x + 1) − 6

Expand:
3x − 12 ≥ 2x + 2 − 6
3x − 12 ≥ 2x − 4

Collect terms:
3x − 2x ≥ −4 + 12
x ≥ 8

The replacement set is I, the integers, so:

**Solution set = {8, 9, 10, 11, ...}** — that is, all integers greater than or equal to 8.

ON THE NUMBER LINE: dots at 8, 9, 10, 11 and so on, with an arrow to the right to show the set continues indefinitely. A closed dot at 8, since 8 is included.

CHECK by substituting a value: x = 8 gives (8−4)/2 = 2 on the left, and (8+1)/3 − 1 = 3 − 1 = 2 on the right. 2 ≥ 2 is true, so 8 belongs to the set. Testing x = 7 gives 1.5 ≥ 1.67, which is false — so the boundary is right.
