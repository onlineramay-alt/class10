For ax² + bx + c = 0:

ROOTS: x = [−b ± √(b² − 4ac)] / 2a
DISCRIMINANT: D = b² − 4ac

D > 0 and a perfect square → roots real, distinct and RATIONAL
D > 0 but not a perfect square → roots real, distinct and IRRATIONAL
D = 0 → roots real and EQUAL
D < 0 → NO real roots

When a question asks for the answer 'correct to two decimal places' or 'correct to three significant figures', the formula must be used — factorisation will not give it.

A. Multiple Choice Questions

Q1. (c) Real, distinct and irrational.

Here a = 2, b = −5, c = 1.
D = b² − 4ac = (−5)² − 4(2)(1) = 25 − 8 = **17**

D = 17 > 0, so the roots are real and distinct. But 17 is NOT a perfect square, so √17 is irrational and the roots are irrational.

THE METHOD FOR EVERY QUESTION OF THIS TYPE: compute D, then ask two questions in order — is D positive, zero or negative? and, if positive, is it a perfect square?

B. Worked Problems

Q2. 3x² − 7x + 2 = 0

SPLIT THE MIDDLE TERM. We need two numbers whose PRODUCT is a × c = 3 × 2 = 6 and whose SUM is b = −7.
Those numbers are −6 and −1, since (−6)(−1) = 6 and (−6) + (−1) = −7.

3x² − 6x − x + 2 = 0

Group in pairs and take out common factors:
3x(x − 2) − 1(x − 2) = 0
(x − 2)(3x − 1) = 0

So x − 2 = 0 or 3x − 1 = 0

**x = 2 or x = 1/3**

CHECK: substitute x = 2 → 3(4) − 7(2) + 2 = 12 − 14 + 2 = 0 ✓
Substitute x = 1/3 → 3(1/9) − 7(1/3) + 2 = 1/3 − 7/3 + 6/3 = 0 ✓

Q3. Here a = 2, b = −7, c = 3.

D = b² − 4ac = (−7)² − 4(2)(3) = 49 − 24 = 25

x = [−b ± √D] / 2a
x = [7 ± √25] / (2 × 2)
x = [7 ± 5] / 4

x = (7 + 5)/4 = 12/4 = 3
or x = (7 − 5)/4 = 2/4 = 0.5

**x = 3.00 or x = 0.50** (correct to two decimal places)

NOTE that here D = 25 is a perfect square, so the roots came out rational and exact. Had D been, say, 17, the working would have continued x = (7 ± 4.123)/4, giving 2.78 and 0.72 — and the decimal places would then have mattered. Always carry one more decimal place through the working than the answer requires, and round only at the end.

Q4. For real and EQUAL roots, the discriminant must be ZERO.

Here a = 1, b = k, c = 9.

D = b² − 4ac = 0
k² − 4(1)(9) = 0
k² − 36 = 0
k² = 36
**k = 6 or k = −6**

BOTH values must be given — omitting the negative root is the commonest error in this question.

CHECK with k = 6: x² + 6x + 9 = 0 → (x + 3)² = 0 → x = −3 twice, so the roots are equal ✓
Check with k = −6: x² − 6x + 9 = 0 → (x − 3)² = 0 → x = 3 twice ✓

Q5. Let the two consecutive natural numbers be x and (x + 1).

Set up the equation from the condition:
x² + (x + 1)² = 313

Expand:
x² + x² + 2x + 1 = 313
2x² + 2x + 1 = 313
2x² + 2x − 312 = 0

Divide throughout by 2:
x² + x − 156 = 0

Factorise — two numbers with product −156 and sum +1: these are 13 and −12.
x² + 13x − 12x − 156 = 0
x(x + 13) − 12(x + 13) = 0
(x + 13)(x − 12) = 0

x = −13 or x = 12

The numbers are NATURAL numbers, so x = −13 is REJECTED.

x = 12, and the next number is 13.

**The numbers are 12 and 13.**

CHECK: 12² + 13² = 144 + 169 = 313 ✓

NOTE the final step. In every word problem leading to a quadratic, one root is usually inadmissible — a negative length, a negative age, a non-natural number — and it must be REJECTED explicitly with a reason. Marks are given for that rejection.
